🎮 How the controls work

Every visualization has the same friendly buttons:

▶ Start — plays all steps automatically
⏸ Pause — stops wherever you are
◀ ▶ Previous / Next — one step at a time
⏪ ⏩ Back 3 / Forward 3 — jump several steps (or drag the step slider)
🔁 Replay — start again from step 1 and play
↺ Reset — back to step 1, paused
🐢 🐇 Speed — slow it down or speed it up

Tip: on a computer you can also use ← / → for 1 step, and Shift + ← / → for 3 steps. 💡

Everything here is a simulation made with JavaScript — no real Java compiler or database is involved. 🧸
