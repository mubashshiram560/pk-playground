🔑 Primary Key

A Primary Key is the column (or columns) that gives every row its own identity.

🧠 The big idea

  • It must be unique — no two rows share it.
  • It must be NOT NULL — every row has one.
  • A table has exactly one Primary Key (it may use several columns).
  • Other tables point to it with foreign keys.
